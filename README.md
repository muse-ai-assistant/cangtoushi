# 🖋️ 藏头诗 · Cangtoushi

输入名字，一键生成藏头诗。水墨宣纸美学，竖排展示。

**在线体验 → https://muse-ai-assistant.github.io/cangtoushi/**

## 功能

- ✍️ 输入 2-8 个字，每字一句，句库随机匹配（文艺 / 搞笑两种风格）
- 📜 竖排展示（从右往左传统排版），红字标出藏头
- 📋 一键复制诗句
- 🖼️ 生成诗笺卡片图（宣纸质感 canvas，可下载分享）
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS 单文件应用，零依赖。`writing-mode: vertical-rl` 实现传统竖排。
